Screen sharing

Show Fairy your screen.

Enter your Discord user ID, choose a screen or window, and ask Fairy about it in your voice channel. MiniCPM can request a visual analysis of your latest shared frame when it needs one to answer. Frames stay briefly in memory and sharing stops when you close this page.

The ID identifies the speaker but does not authenticate them. This service is for local use only. Discord Go Live is not connected.
