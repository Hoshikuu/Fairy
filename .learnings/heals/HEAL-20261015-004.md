## [HEAL-20261015-004] Readiness con redirectores de Windows

**Logged**: 2026-10-15
**Status**: verified
**Trigger**: tool-failure
**Area**: processes
**Priority**: high

### Failure

El diagnóstico intentó HTTP tras EOF. Posteriormente esperó 240 segundos
aunque los servicios anunciaban estar listos.

### Diagnosis

EOF no prueba readiness. Popen.pid puede ser el PID del redirector del venv,
diferente del intérprete que escribe el JSON.

### Fix

JSON atómico con token UUID por ejecución, supervisor activo y espera acotada.
El diagnóstico reutiliza el protocolo; se completó su import de Path.

### Verification

Check explícito de token con PIDs diferentes y rechazo de otro token.
Pipeline real hasta 147 paquetes Opus, supervisor código 0. Orden de arranque
y cierre real conjunto comprobados; no acredita audio audible en Discord.
