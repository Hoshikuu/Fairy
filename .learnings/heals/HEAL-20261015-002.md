### Failure

OpenAI 3.13.0 estaba instalado pese al rango openai<3. Un check restringido
también declaraba Python inutilizable.

### Diagnosis

Existían pins transitivos manuales. El acceso al Python Microsoft Store fallaba
en el sandbox, pero Python 3.12.10 funcionó fuera de él. No se confirmó un
intérprete eliminado. asyncio.timeout y Kokoro delimitan versiones de Python.

### Fix

Requisitos directos y entornos separados; OpenAI 2.54.0 y Hub 0.36.2 en el bot.
Checks de versiones, SHA Git DAVE y pip check. Rango de aplicación 3.11–3.12.

### Verification

Setup --only bot --check, main --check y setup --check pasan. Ambos pip check
devuelven No broken requirements found. SHA-256 de los tres modelos correcto.
